# ETF Search

국내 상장 ETF 1,100여 개와 해외(미국) 상장 ETF 1,500여 개를 **쉽게 이해하고, 비교하고, 후보를 좁혀보는** 앱입니다.
투자 성향과 기간을 고르면 과거 성과·위험·비용·거래량을 점수화해 후보를 보여주고,
각 ETF가 *무엇인지*, *왜 이 점수인지*, *무엇을 조심해야 하는지*를 한국어로 설명합니다.

> ⚠️ **투자 자문이 아닙니다.** 점수는 과거 데이터로 후보를 좁히는 필터이지 미래 수익률 예측기가 아닙니다.
> 과거 성과가 미래를 보장하지 않으며, 백테스트에서도 점수의 예측력은 통계적으로 확정되지 않았습니다.
> 자세한 내용은 [docs/DESIGN.md](docs/DESIGN.md)와 [docs/BACKTEST.md](docs/BACKTEST.md)를 참고하세요.

## 주요 기능

| 화면 | 하는 일 |
|---|---|
| **추천** | 투자 성향(안정/중립/공격) × 기간(1년 미만/1~3년/3년 이상) × 자산군에 맞는 상위 후보. 추천 사유·주의사항·위험 등급·항목별 점수. 제외된 ETF와 그 이유까지 공개 |
| **탐색** | 전체 ETF 검색·필터(상장 시장 포함)·정렬(수익률, 변동성, 낙폭, 보수, 순자산, 거래대금 …), 2~4개 선택해 비교 |
| **상세** | "이 ETF는 무엇인가요?" 해설, 운용사 설명, 핵심 지표, 가격 차트, **구성종목 상위 10·집중도·구성이 비슷한 ETF**, 구조적 주의사항, 같은 지수 ETF 비교표 |
| **비교** | 최대 4개 ETF를 시작=100으로 맞춘 차트 + 지표 비교 + **구성종목 겹침 행렬**·공통 종목 |
| **조합** | 추천 후보에서 서로 다르게 움직이고 구성종목이 겹치지 않는 **2~3개 조합과 비중** 제안. 분산 효과·겹침·과거 낙폭과, 현재 선택에 해당하는 **검증 수치**를 함께 표시 |
| **배우기 / 방법론** | ETF 고르는 6단계, 용어 사전, 점수 계산법·검증 결과·한계 |

핵심 설계 포인트
- **같은 지수 ETF는 하나로 묶습니다.** S&P500 ETF가 10개여도 대표 1개만 추천하고 나머지는 "대안"으로 보여줍니다(총보수·규모·거래대금으로 비교).
- **위험한 구조는 기본으로 걸러냅니다.** 레버리지·인버스, 순자산이 작은 ETF, 거래가 거의 없는 ETF, 상장 1년 미만은 점수와 무관하게 먼저 제외합니다(설정에서 포함 가능).
- **구성종목까지 들여다봅니다.** 이름이 달라도 같은 종목을 담은 ETF(S&P500↔나스닥100 약 55% 겹침)를 찾아주고, 다른 ETF를 담은 TDF 같은 상품은 풀어서(look-through) 계산합니다.
- **국내와 해외(미국) 상장 ETF를 한 목록에서 봅니다.** 추천·탐색·비교·조합 모두 '전체 / 국내 상장 / 해외(미국) 상장'으로 좁힐 수 있고, 해외는 **달러 가격에 같은 날 원/달러 환율을 곱한 원화 기준**으로 계산해 환율 변동이 수익률·변동성·낙폭에 그대로 들어갑니다.
  다만 점수식의 백테스트 검증은 국내 상장 ETF로만 했고 해외 ETF의 생존편향은 보정하지 못했습니다(아래 '데이터와 한계').
- **수익률은 분배금이 보정된 수정주가 기준**이라 분배금이 많은 ETF(커버드콜 등)가 불리하게 비교되지 않습니다.
- 한국 증시 관례에 맞춰 **상승=빨강, 하락=파랑**이며 부호를 항상 같이 표기합니다.

## 빠르게 시작하기

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev        # http://localhost:5173
```

저장소에는 **데이터 스냅샷이 포함**되어 있어 바로 실행됩니다(`public/data/`).
최신 데이터로 갱신하려면:

```bash
npm run sync       # 국내(네이버 금융)·해외(야후 파이낸스·나스닥 목록)에서 목록·상세·8년치 시세·구성종목 수집 → 스냅샷 재생성 (수 분 소요)
npm run backtest   # 수집된 시세로 워크포워드 백테스트 → docs/BACKTEST.md, public/data/backtest.json
```

| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 검사 + 정적 빌드(`dist/`) |
| `npm run preview` | 빌드 결과 미리보기 |
| `npm test` | 단위 테스트 |
| `npm run typecheck` | 타입 검사 |
| `npm run sync [-- --force] [-- --limit N] [-- --skip-holdings] [-- --skip-us] [-- --us-limit N]` | 데이터 수집. 같은 날 받은 캐시(`.cache/`)는 재사용, `--force`로 무시, `--skip-holdings`는 구성종목 수집 생략, `--limit`은 국내에만 적용. 해외(미국) 수집은 `--skip-us`로 건너뛰는데 이때 스냅샷에서 해외 ETF가 빠지므로 경고를 냅니다. `--us-limit N`은 개발용(1차 필터를 통과한 해외 ETF 중 거래대금 상위 N개만) |
| `npm run backtest` | 백테스트 |

프록시 환경에서 Node 내장 `fetch`가 프록시를 쓰지 않는다면 `NODE_USE_ENV_PROXY=1 npm run sync` 로 실행하세요(Node ≥ 22.21). 프록시를 거치지 않으면 네이버가 `HTTP 403`으로 거절하는 환경이 있습니다.
해외 수집은 야후의 호출 제한(HTTP 429)에 걸려 일부 종목이 실패할 수 있는데, 단계별로 후보의 10%를 넘게 실패하면 중단하고 아무것도 저장하지 않습니다. 몇 건 실패하고 끝났다면 같은 날 다시 실행하세요(받은 것은 캐시에서 읽고 실패한 것만 다시 받습니다).

### 배포
`npm run build` 결과물(`dist/`)은 **서버가 필요 없는 정적 파일**입니다(해시 라우팅, 상대 경로).
GitHub Pages, Netlify 등 어디에나 올릴 수 있습니다. 데이터를 최신으로 유지하려면 배포 전에 `npm run sync`를 실행하세요.

## 구조

```
src/
├─ core/     순수 로직(I/O 없음, 브라우저·Node 공용)
│  ├─ taxonomy.ts   이름 기반 자산군·지역·테마·구조 분류, 동일 지수 그룹키(국내 상장)
│  ├─ taxonomy-us.ts 해외(미국) 상장 ETF 분류: 모닝스타 카테고리 + 영문 이름 규칙, 같은 지수 그룹키
│  ├─ market.ts     상장 시장(국내/해외) 구분, 해외 수집 기준 상수
│  ├─ market-view.ts 시장 필터·개수·검색·순자산 표기 등 화면용 순수 함수
│  ├─ metrics.ts    시세 → 수익률·변동성·최대낙폭·샤프 등 (달력 기준 기간)
│  ├─ scoring.ts    자격 심사 → 6개 항목 점수 → 성향/기간별 가중합 → 중복 제거·다양화
│  ├─ holdings.ts   구성종목 분류(현금·파생·ETF·종목)와 look-through 환산
│  ├─ overlap.ts    구성종목 겹침(Σ min 비중)·공통 종목·집중도·겹침 순위
│  ├─ portfolio.ts  2~3개 조합 제안(후보 풀·비중·분산 효과·성향 한도)
│  ├─ explain.ts    추천 사유·주의사항·위험 등급·세금 안내·조합 설명 생성
│  ├─ glossary.ts   용어 사전
│  └─ format.ts     숫자 포맷터
├─ sync/     Node 전용 데이터 파이프라인
│  ├─ naver.ts          네이버 금융 클라이언트(목록/상세/시세) + 재시도
│  ├─ yahoo.ts          야후 파이낸스 클라이언트(쿠키·crumb 세션, 일별 시세, 펀드 정보) + 응답 검증
│  ├─ us.ts             해외(미국) 상장 ETF 수집: 나스닥 목록 → 거래대금·순자산 선별 → 원화 환산 → 레코드
│  ├─ cache.ts, rounding.ts 같은 날 캐시, 직렬화 반올림
│  ├─ build-snapshot.ts 수집 → 분류·지표 계산 → public/data/*.json
│  ├─ build-holdings.ts 구성종목 → 노출 계산 → holdings.json
│  ├─ delisted.ts       (선택) 상장폐지 ETF CSV 가져오기
│  ├─ derive-delisted.ts KRX 과거 시점 '전종목 시세' 파일 → 상장폐지 ETF 목록 도출·검증
│  ├─ backtest.ts       종목 점수 워크포워드 백테스트
│  └─ backtest-combos.ts 조합 제안 워크포워드 검증
└─ web/      React SPA (Vite)
public/data/ snapshot.json(지표), series.json(주간 종가), holdings.json(구성종목), backtest.json(검증 요약)
data/        delisted.csv(상장폐지 ETF 목록)·delisted.meta.json(목록을 만든 KRX 기준일). 만드는 법은 data/README.md
scripts/     개발용 도구(분류 점검 audit-taxonomy.ts·audit-taxonomy-us.ts, 추천 미리보기 preview.ts)
```

런타임에 서버나 외부 API 호출이 없고, 점수는 브라우저에서 계산합니다.
그래서 성향·옵션을 바꾸면 즉시 결과가 바뀌고, 정적 호스팅만으로 충분합니다.

## 데이터와 한계 (요약)

- 출처: 국내는 네이버 금융, 해외(미국) 상장은 야후 파이낸스(시세·분배금·환율·순자산·총보수·카테고리)와 나스닥 ETF 목록으로, 모두 **비공식 공개 엔드포인트**입니다. 형식이 바뀌면 `sync`가 명확한 오류로 멈추도록 응답을 검증하지만, 언제든 깨질 수 있습니다. 실시간이 아니며 오류·지연이 있을 수 있습니다.
- **해외(미국) 상장 ETF**(상세는 [docs/DESIGN.md](docs/DESIGN.md) §13): 나스닥 ETF 목록 5,251개에서 ETN 50개를 빼고, 일평균 거래대금 10억원·순자산 5,000억원 이상인 **1,589개만** 수집했습니다(1차 거래대금 2,704개 통과 → 2차 순자산 통과, 순자산을 알 수 없는 27개는 제외). 다른 나라에 상장된 ETF는 목록을 구할 곳이 없어 넣지 못했습니다.
  달러 수정종가에 같은 날 환율을 곱해 원화 시계열로 바꿔 국내와 같은 지표를 계산합니다(국내 시세 기준일과 해외 시세 기준일, 환산 환율 날짜는 화면에 따로 표시).
  **① 백테스트는 국내 상장 ETF로만 했습니다**(해외에서도 점수식이 통하는지는 확인하지 못했고 국내 백테스트 결과는 해외 편입 전과 바이트 단위로 같습니다). **② 해외 ETF의 생존편향은 보정하지 못했습니다**(사라진 ETF의 목록이 없음). **③ 선택 편향**: 현재 순자산이 큰 것만 모아 과거 성과가 좋았던 종목이 많이 남아 있어 국내 ETF보다 점수가 유리하게 나올 수 있습니다.
  **④ 순자산은 야후의 펀드 단위 값**이라 뮤추얼펀드 클래스와 한 몸인 뱅가드 ETF 92개(VTI·VOO 등)는 다른 클래스까지 합친 값이 나옵니다(화면에 † 표시, 실제 ETF 규모보다 훨씬 큼). ⑤ 괴리율과 구성종목 겹침은 해외 ETF에는 제공하지 않습니다. 분류는 모닝스타 카테고리와 영문 이름 규칙이라 오분류가 있을 수 있습니다.
- 분류는 ETF **이름 규칙**으로 자동 판별해 일부 오분류가 있을 수 있습니다.
- 시세는 최근 약 8년(2,000거래일)만 수집하므로 더 오래된 ETF의 실제 상장일은 알 수 없습니다(화면에는 "8년 이상"으로 표기).
- 환율·금리 전망, 밸류에이션은 반영하지 않습니다(해외 ETF는 과거 환율 변동이 수익률에 들어가지만 미래 환율은 예측하지 않습니다). 구성종목 겹침은 레버리지·인버스·합성 ETF(179개)와 종목 식별 비중이 50% 미만인 ETF(13개)에는 계산하지 않습니다(980/1,172개 계산 가능).
- 조합 제안은 **수익을 예측하지 않습니다.** 앱이 제안하는 방식(3개·역변동성)에서 통계적으로 확인된 것은 중립·공격형의 3·6개월 보유 중 낙폭 감소뿐이고(12개월과 안정형은 표본이 작아 유의하지 않음), 수익 개선은 어느 변형에서도 확인되지 않았습니다.
- 백테스트의 **생존편향은 부분만 보정**했습니다. KRX 전종목 시세 12개(2020-12-30~2026-04-10, 6개월 간격)로 상장폐지된 ETF 173개를 포함했고 백테스트 구간(2021-01~) 전체를 덮습니다. 종합점수 모델의 결론(후보 중앙값과 우연 이상으로 구분되지 않음)은 바뀌지 않았고,
  변화는 안정형에서 상대적으로 컸습니다(안정형이 고르는 만기 채권형 ETF가 상장폐지 후보에 많음). 2020-12~2022-12 파일로 추가된 31개는 거래대금·레버리지 게이트에 걸려 결과를 바꾸지 않았습니다. 파일 날짜 사이에 새로 상장했다가 다음 파일 전에 폐지된 ETF는 이 방법으로 볼 수 없어 빠져 있습니다(`data/README.md`).
  신뢰구간은 겹치지 않는 표본(보유 기간 간격의 달, 시작 달을 모든 경우로 바꿔 평균)이 2~22개뿐이라 t 분포로 계산합니다. 그 외 짧은 단일 장세, 표본 중첩 한계가 있습니다.
