# 백테스트 리포트 (워크포워드)

- 생성: `npm run backtest` · 데이터 기준일 20261008 · 대상 ETF 1274개 · 월말 기준일 66개
- 방법: 각 월말 시점의 데이터만으로 점수 산출 → 선택한 상위 10개(자산군·테마당 최대 2개)의 이후 3·6·12개월 실제 수익률을 같은 시점 후보군(게이트 통과, 동일 지수 대표) **중앙값**과 비교.
- 후보군·투자 성향 한도·게이트는 실제 앱과 같은 코드를 사용. 단, 과거 시점의 총보수·순자산은 알 수 없어 비용은 중립(50점), 순자산은 통과값으로 고정.

- **상장폐지 ETF 142개 포함**(data/delisted.csv, KRX 전종목 시세 2023-04-10·2023-10-10·2024-04-11·2024-10-10·2025-04-10·2025-10-10·2026-04-10 기준). 보유 도중 시세가 끝난 ETF는 마지막 가격에 청산된 것으로 계산했습니다. **부분 보정입니다** — 2023-04-10 이전에 상장폐지된 ETF, 그리고 기준일들 사이에 새로 상장했다가 다음 기준일(없으면 현재) 이전에 폐지된 ETF는 여전히 빠져 있어 생존편향이 남아 있습니다.
> **해석 시 주의** — 생존편향(상장폐지 ETF는 일부만 포함 — 위 항목 참고), 한 번의 장세에 집중된 짧은 표본, 월별 표본의 중첩, 거래비용·세금 미반영. '초과수익'은 후보군 중앙값 대비이며 절대 수익을 보장하지 않습니다. 비중첩 표본의 95% 신뢰구간(표본이 2~22개뿐이라 t 분포 사용)이 0을 포함하면 우연과 구분되지 않습니다.
