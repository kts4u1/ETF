# data/

## delisted.csv (선택)

상장폐지된 ETF 목록. 있으면 `npm run sync`가 시세를 받아 `npm run backtest`의 유니버스에 포함해
**생존편향**(현재 상장 중인 ETF만 평가해서 부진했던 ETF가 빠지는 문제)을 줄입니다. 없으면 이 단계는 건너뜁니다.

- 어디서 받나: KRX 정보데이터시스템(data.krx.co.kr) → 상장폐지종목현황(로그인 필요)에서 증권구분을 ETF로 내려받은 CSV.
  자동 수집은 로그인·접근 제한으로 할 수 없어 직접 받아야 합니다.
- 형식: 헤더가 있는 CSV 또는 TSV. UTF-8과 EUC-KR(KRX 기본) 모두 읽습니다.

  | 열 | 필수 | 설명 |
  |---|---|---|
  | 종목코드 (또는 단축코드, code) | ✅ | 6자리. `A069500`처럼 `A`가 붙어도 됩니다 |
  | 종목명 (또는 name) | ✅ | 자산군·테마 분류에 사용 |
  | 상장폐지일 (또는 delistedOn) | | `YYYYMMDD`, `YYYY-MM-DD`, `YYYY/MM/DD` |

- 시세는 네이버 금융에서 받습니다(상장폐지 종목의 과거 시세도 제공하는 것을 주식으로 확인했습니다. ETF는 확인하지 못했고,
  받지 못한 종목은 사유와 함께 건너뜁니다).
- 보유 도중 시세가 끝나는 ETF는 **마지막 가격에 청산된 것으로** 계산합니다(평가에서 조용히 빠지지 않습니다).
- 이 파일은 개인 데이터라 저장소에 포함하지 않습니다. 형식은 `delisted.example.csv`를 참고하세요.
